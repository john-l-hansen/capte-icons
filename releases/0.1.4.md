# Capte Icons 0.1.4 — Review build

This build keeps the three approved pilot icons and simplifies the plugin around the supplied Material Symbols reference.

- Category/search row, Weight, Style, Grade, Optical size, an icon-only grid, and Insert icon.
- Header and plugin dark-mode UI removed. Optical sizes display in dp; numeric Figma dimensions are unchanged.
- Insert icon replaces one selected plugin-generated Capte icon. Deselect first to add another. Live editing remains enabled.
- Inserted/updated strokes become filled paths. Distinct paint roles remain separate and editable.
- Fills bind to published Capte variables when accessible; otherwise reusable local Capte Icons tokens are attached. Local values are preserved across later inserts.
- Documentation reference and outbound icon are present, with no URL and no active navigation yet.

## Verified

TypeScript, 17 renderer/controller tests, all 648 renderer configurations, plugin/explorer builds, and Chromium UI checks pass. Native Figma API checks of the three duotone pilot icons confirmed filled output with zero live strokes. Search and category filtering remain covered. Full Figma Desktop insertion, token behavior, and undo/redo still need the next review.

## Limits

Only plugin-generated icons are replaced; unrelated artwork and component instances are preserved. Local tokens do not synchronize with the source library. The catalog remains Search, Shield Lock, and Location Check. No Community publication, website deployment, or stable release is included.
