# Capte Icons 0.1.9 — Diagnostic review build

This build helps identify an insertion failure reported in Figma Desktop. The cause in the editor remains unconfirmed.

- Shows the running version, connection acknowledgment, and progress during insertion.
- Reports when Figma has not responded within 12 seconds, including the last stage reached.
- Logs controller startup messages, received UI requests, progress, and errors with a Capte Icons prefix.
- Keeps insertion success visible after selection synchronization.
- Adds a browser integration check connecting the built UI to the bundled controller using the Figma API harness, testing insertion and in-place replacement.

The same centering, replacement, artwork, and token behavior is retained. Actual Figma Desktop verification is pending.
