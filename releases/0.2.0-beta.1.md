# Capte Icons 0.2.0-beta.1 — Catalog preview

Prepared for owner review; publication has not yet been approved.

- Expand the shared catalog from 3 to 60 icons.
- Provide 20/24/40/48 dp sizes, Thin/Medium/Heavy weights, three grades and Outline/Filled/Duotone styles.
- Add semantic categories and search keywords.
- Preserve the approved pilot geometry and explicit Insert icon / Update icon behavior.
- Add source snapshots, reproducible generation, filled contrast roles and catalog-wide tests.
- Rename the development-plugin entry to Capte Icons; retain its assigned plugin ID.

New icon sizes use proportional source paths with the existing optical stroke profiles. They do not yet have individually approved small-size geometry. Dense illustrations, especially Measurable Performance, deserve a close 20/24 dp review. Filled crossing marks and interior contrast have been reviewed in the generated contact sheet.

Verification: typecheck, 32 tests covering 12,960 renderer configurations, browser checks, and native Figma SVG import/outline/token probes for all 60 icons at 48 dp Duotone and 20 dp Filled (Heavy/Emphasis). These do not replace an installed-plugin acceptance pass.

Extract the ZIP into a permanent folder. Keep manifest.json, code.js and ui.html together. In Figma Desktop import the manifest through Plugins → Development, then run Capte Icons. Reopen the plugin after replacing files. Old icons remain editable through their stable IDs.
