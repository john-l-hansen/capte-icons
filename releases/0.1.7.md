# Capte Icons 0.1.7 — Review build

- New icons center over the selected object's bounds, or combined bounds for multiple objects.
- With no selection, insertion centers in the overall editable frame beneath the viewport center, with a viewport-center fallback on empty canvas.
- Insertion uses the shared editable frame where available and absolute positioning in auto-layout frames. Rotated frame coordinates are supported.
- Selecting an existing Capte icon still replaces it in place.
- Changing selection while color tokens load safely cancels the pending insertion.

Typecheck, controller/renderer tests, and plugin/docs build passed. Figma Desktop verification is pending.
