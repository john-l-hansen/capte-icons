# Capte Icons 0.1.12 — Review build

- Weight, style, grade, size, and icon changes ask the controller to update the actual selected Capte icon, even if the UI missed its selection notification.
- Insert resolves the current Figma selection at receipt and replaces a selected owned icon instead of depending on the UI’s cached selection ID.
- Successful actions include selected-root metadata so the UI can recover selection state immediately.
- The controller captures the target before queuing the edit and retains asynchronous selection checks to avoid updating a different icon.
- No selection means controls only configure the next insertion. Unrelated artwork is not overwritten.

Tests include live editing after dropping selection notifications. Actual Figma Desktop verification remains pending.
