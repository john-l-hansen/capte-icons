# Capte Icons 0.1.3 — Team preview

A ready-to-install preview for testing the Capte icon workflow. **Includes three pilot icons: Search, Shield Lock, and Location Check.** This is not the complete catalog or a Figma Community release.

[Installation guide](https://github.com/john-l-hansen/capte-icons/blob/v0.1.3/INSTALL.md) · [Usage](https://github.com/john-l-hansen/capte-icons/blob/v0.1.3/docs/usage.md) · [Roadmap](https://github.com/john-l-hansen/capte-icons/blob/v0.1.3/docs/roadmap.md) · [Report a bug](https://github.com/john-l-hansen/capte-icons/issues/new?template=bug_report.yml)

## Download and install

Download **capte-icons-figma-plugin-0.1.3.zip** from this release's Assets. Extract it to a permanent folder, then use Figma Desktop → Plugins → Development → Import plugin from manifest… and select `manifest.json`. Run **Capte Icons — Pilot**.

No build tools, API keys, or source-file access are needed. Installation and usage guides are included in the ZIP. GitHub's automatic “Source code” downloads are for developers.

## Included

- Editable vector icons at 20, 24, 40, and 48 px.
- Thin/Medium/Heavy weight; Dark/Normal/Emphasis grade; Outline/Filled/Duotone style; Light/Dark palettes.
- Selected Capte icons update live as controls or icon choices change.
- **Insert icon** always creates an additional icon.
- Capte design-system colors, typography, spacing, and radii in the shared plugin/explorer UI.
- Bundled fonts and artwork for offline plugin use.
- Saved preferences and metadata for re-editing inserted icons.

## Update an existing copy

Close the plugin, replace `manifest.json`, `code.js`, and `ui.html` in the existing plugin folder, then reopen it. Keep the same folder path. Re-import the manifest if you moved it or Figma still points to an older copy.

## Verification and limits

TypeScript, 13 renderer/controller tests, all 648 configurations, both builds, and Chromium browser checks passed during preparation. Interface screenshots were reviewed in Light/Dark modes. An earlier pilot launch and initial appearance were confirmed by the project owner.

**The complete 0.1.3 Figma Desktop live-editing and undo/redo checklist remains pending.** Controller tests use a mocked API. Use this release for team testing and feedback.

Only plugin-created icons are live-edited; multiple selections and locked roots are not edited. Setting changes replace generated children and overwrite manual child edits. Inserted icons are fixed-color snapshots, not linked library components. After undo/redo, re-select an icon to reload its stored settings. Installed development plugins and existing canvas artwork do not automatically receive GitHub updates.
