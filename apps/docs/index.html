A shared visual language.

This pilot contains Search, Shield Lock, and Location Check. Its previews and the Figma plugin use the same approved artwork and rendering rules. The complete icon collection will follow after insertion and editing have been validated in Figma Desktop.

Install the development plugin

  1. Clone the repository and run npm ci.
  2. Run npm run build. The manifest is configured for the assigned Capte development plugin ID.
  3. In Figma Desktop, use Plugins → Development → Import plugin from manifest and choose apps/figma-plugin/dist/manifest.json.
  4. Run Capte Icons, choose an icon and settings, and click Insert icon.

For your own separate development plugin, use npm run configure:plugin -- YOUR_PLUGIN_ID and rebuild. The pilot is a local development build. A public Community installation link will be added after release.

Choose the right treatment

ControlWhat it changes
Optical size20, 24, 40 or 48 dp (the same numeric SVG/Figma dimensions). Small artwork has deliberate adjustments for compact details.
WeightThin, Medium or Heavy establishes the base stroke thickness.
GradeDark slightly reduces the stroke, Normal preserves the baseline, and Emphasis adds thickness.
StyleOutline, Filled or the original Duotone treatment.
ColorLight or Dark palette, selected in the top-right. This is independent of Grade.

Update an inserted icon

Select one icon inserted by this plugin, or a vector inside it. The plugin loads its saved settings. Changes to size, weight, grade, style, or icon choice apply immediately. The plugin uses the Light palette; the explorer retains its palette control. Click Insert icon to replace the selected plugin-generated icon. Deselect it first to create another. Its root layer and placement are retained; generated artwork is replaced. Manual edits inside the icon are overwritten.

Use on the web

Download or copy the SVG at the intended size. Use empty alternative text for decorative images. Give meaningful icons an accessible name, and label buttons that would otherwise contain only an icon. Check contrast on the actual page background.

Web SVG exports retain fixed colors and live strokes. Figma insertion converts strokes to filled paths and binds colors to published Capte variables or reusable local tokens. Source geometry updates still require reinsertion or editing through the plugin.

How this library is maintained

Artwork is designed and approved in Figma, exported into a versioned catalog, and rendered by the same package in the plugin and explorer. Stable IDs connect names, search terms, and saved settings.
